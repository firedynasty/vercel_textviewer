# Basic Vercel App

A React file reader with a live feed for notes, images, and videos.

For the live feed, background folder server, and Finder Quick Action, see
[local_feed/README.md](local_feed/README.md). Build with `npm run build:feed`,
then open a folder with `npm run feed -- "/path/to/notes"`.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Features

- Click the button to display "Hello World!" message
- Responsive design
- Ready for Vercel deployment

## Deployment

This app is configured for easy deployment to Vercel. Simply connect your repository to Vercel and it will automatically deploy.

## Available Scripts

- `npm start` - Runs the app in development mode
- `npm run build` - Builds the app for production
- `npm test` - Launches the test runner
- `npm run eject` - Ejects from Create React App (one-way operation)# vercel_textviewer
